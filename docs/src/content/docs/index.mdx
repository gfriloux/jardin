  </Card>
  <Card title="La méthode" icon="list-format">
    Dix objectifs numérotés, chacun avec un critère de sortie vérifiable. On

  </Card>
  <Card title="L'état" icon="approve-check">

    marge.
    Reste **O2**, qui attendait un multiplexeur désormais livré, et **O5**, la
    chaîne de données — la dernière des quatre questions du POC.
  </Card>
