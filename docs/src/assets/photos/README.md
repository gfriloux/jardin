# Photos des ateliers

Déposer ici les photos prises pendant les ateliers, nommées
`<objectif>-<numéro>-<sujet>.jpg` — par exemple `o1-04-oled-allume.jpg`.

La liste de ce qu'il faut photographier, le cadrage attendu et la façon de les
insérer dans les pages sont dans la documentation :
`docs/src/content/docs/materiel/photos.md`.

Astro optimise et redimensionne les images à la compilation : inutile de les
compresser avant de les déposer.
